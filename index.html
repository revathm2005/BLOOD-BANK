Blood Type Compatibility Quick Reference Guide

Vital reference for emergency issue transactions and donor triage:

O- (Universal Red Cell)

Can donate red blood cells to ANY blood type (A+, A-, B+, B-, AB+, AB-, O+, O-).

AB+ (Universal Recipient)

Can receive red blood cells from ANY blood type.

Rh Factor Compatibility

Negative types (-ve) can safely donate to positive (+ve) types, but positive cannot donate to negative.
